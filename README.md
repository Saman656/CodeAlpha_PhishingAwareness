# CodeAlpha Phishing Awareness Training

## Project Overview

This project is a phishing awareness training presentation created as part of the CodeAlpha Cyber Security Internship.

## Topics Covered

- What is phishing?
- How to recognize phishing messages
- Fake websites and suspicious links
- Social engineering tactics
- Real-world phishing examples
- Best practices for protection
- Phishing awareness quiz

## Objective

The objective of this project is to educate users about common phishing techniques and provide practical steps to identify and avoid phishing attacks.

## Tools Used

- Microsoft PowerPoint
- Cybersecurity awareness concepts

Developed as part of the CodeAlpha Cyber Security Internship.
